## Important interpretation note

Do not infer a physical copper layer only from the apparent color in JLC's composite viewer. Multiple enabled semitransparent layers overlap, so top copper covered by solder mask and lying above an inner ground plane can appear with the inner-layer color in the combined view.

The V1.0D fabrication files themselves define:

- `.GTL`: all SMT copper pads and the RF/supply routing on L1 Top;
- `.G2L`: solid GND plane on L2;
- `.G3L`: solid GND plane on L3;
- `.GBL`: bottom GND copper / SMA ground lands on L4.
