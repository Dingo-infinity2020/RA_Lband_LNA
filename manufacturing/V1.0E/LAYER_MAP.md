# V1.0E JLC layer map

| File | Function |
|---|---|
| RA-LNA-L1_V1.0E.GTL | Top copper (all SMT pads and RF routing) |
| RA-LNA-L1_V1.0E.G2L | Inner layer 1, solid GND |
| RA-LNA-L1_V1.0E.G3L | Inner layer 2, solid GND |
| RA-LNA-L1_V1.0E.GBL | Bottom copper/GND |
| RA-LNA-L1_V1.0E.GTS | Top solder mask |
| RA-LNA-L1_V1.0E.GBS | Bottom solder mask |
| RA-LNA-L1_V1.0E.GTP | Top paste |
| RA-LNA-L1_V1.0E.GTO | Top silkscreen |
| RA-LNA-L1_V1.0E.GKO | Board outline |
| RA-LNA-L1_V1.0E.XLN | PTH drill |

JLC must recognize exactly four copper layers. If `.GTL/.G2L/.G3L/.GBL` are shown as miscellaneous/unknown layers, stop the order.
