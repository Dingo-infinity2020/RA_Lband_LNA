# V1.0D JLC layer map

| File | Function |
|---|---|
| RA-LNA-L1_V1.0D.GTL | Top copper (all SMT pads and RF routing) |
| RA-LNA-L1_V1.0D.G2L | Inner layer 1, solid GND |
| RA-LNA-L1_V1.0D.G3L | Inner layer 2, solid GND |
| RA-LNA-L1_V1.0D.GBL | Bottom copper/GND |
| RA-LNA-L1_V1.0D.GTS | Top solder mask |
| RA-LNA-L1_V1.0D.GBS | Bottom solder mask |
| RA-LNA-L1_V1.0D.GTP | Top paste |
| RA-LNA-L1_V1.0D.GTO | Top silkscreen |
| RA-LNA-L1_V1.0D.GKO | Board outline |
| RA-LNA-L1_V1.0D.XLN | PTH drill |

JLC must recognize exactly four copper layers. If `.GTL/.G2L/.G3L/.GBL` are shown as miscellaneous/unknown layers, stop the order.
